Soreuso Lab Studio Tool

A private, self-hosted production tool for one YouTube channel

Soreuso Lab Studio Tool is a private, self-hosted production tool for the YouTube channel “Soreuso Nanoda Kenkyujo” (youtube.com/@soreuso-nanoda), a Japanese educational channel that fact-checks common myths with cited sources.

The tool is used only by the channel owner, on the owner's own computer. It is not offered to other users.

What the tool does (uses YouTube API Services)

  • Uploads videos that the channel owner has reviewed and approved, with title, description, tags, thumbnail and scheduled publish time (YouTube Data API).
  • Reads performance numbers of the channel's own videos (views, watch time, likes, comments, subscribers gained) to plan better educational videos (YouTube Analytics API, YouTube Reporting API).
Every upload requires a manual approval by the channel owner, who checks the video, the description and the list of sources.
