Privacy Policy

Soreuso Lab Studio Tool · Last updated: October 2026

Soreuso Lab Studio Tool (“the Tool”) is operated by Soreuso Lab for managing the operator's own YouTube channel. The Tool uses YouTube API Services. By using the Tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

1. Information the Tool accesses

With the channel owner's permission (Google OAuth), the Tool accesses:

  • Videos uploaded by the Tool and their metadata (title, description, tags, thumbnail, publish time)
  • The channel's list of its own videos
  • Analytics of the channel's own videos (views, watch time, average view duration and percentage, likes, comments, subscribers gained and lost, impressions and click-through rate)

The Tool does not access data of other YouTube users, and does not collect information from viewers.

2. How the information is used

Only to upload approved videos to the owner's channel and to show the owner how the channel's videos perform, so that better videos can be planned.

3. Storage and sharing

Data is stored only on the operator's own computer (a local SQLite database). It is not sold, shared with or disclosed to any third party. Google OAuth tokens are stored locally and are never displayed or transmitted anywhere except to Google.

4. Retention and deletion

Analytics data obtained from YouTube API Services is refreshed or deleted within 30 days, as required by the YouTube API Services Developer Policies. The owner can delete all stored data at any time by removing the local database.

5. Revoking access

Access can be revoked at any time from the Google security settings page: security.google.com/settings/security/permissions
